# ГЕОПУЛЬС — краткое ТЗ v0.1

> **Суть:** веб-сервис тепловых карт плотности организаций по городам России. Помогает предпринимателю малого бизнеса **визуально оценить конкурентную среду** и выбрать район для открытия точки — там, где гиганты (Яндекс Геоаналитика, 2ГИС Про) не работают или стоят неподъёмно.

**Позиционирование:** «Карта пустых зон. Не прогноз трафика, а ответ на вопрос — где уже есть бизнес, а где его нет».

**Формула:** открытые данные (OSM, Росстат) → агрегация по сетке H3 → тепловая карта → список POI → решение о локации.


## 1. Аудитория

| Сегмент | Что получает |
|---|---|
| **Предприниматель малого бизнеса** (B2C) | Визуальная оценка конкурентной среды, список районов для проверки |
| **Город:** Томск → Барнаул, Кемерово, Тюмень | Ниша: города, где нет Яндекс Геоаналитики (16 миллионников) и недоступен 2ГИС Про (от 36 000 ₽/мес) |

**Не для:** крупных сетей (свои аналитики), консалтинга (2ГИС Про), франшиз (отложено).


## 2. Данные

**Только открытые, только легальные.**

| Источник | Что даёт | Как получать |
|---|---|---|
| **OpenStreetMap (OSM)** | POI всех типов: кафе, аптеки, магазины, фитнес, салоны | Overpass API, `osmnx` |
| **Overture Maps** | Дополнительные POI (резерв) | API |
| **Росстат** | Население, demographics (позже) | Открытые данные |
| **Росреестр** | Кадастровая стоимость (позже) | Открытые данные |

**Категорически не используем:** парсинг 2ГИС (запрещён соглашением), парсинг Яндекс.Карт (серая зона). Это снимает 99% юридических рисков.

**Категории MVP (8):** `cafe`, `restaurant`, `bar`, `pharmacy`, `beauty`, `fitness`, `grocery`, `pickup_point`.


## 3. Расчёты

### MVP (только агрегация, без прогнозов)

| Расчёт | Что делает |
|---|---|
| **Плотность POI** | Количество организаций категории в H3-ячейке (~200 м) |
| **Тепловая карта** | Цвет ячейки по `poi_count`: мало → много |
| **Список POI** | Название, адрес (если есть в OSM) для каждой ячейки |

### Фаза 2 (индекс привлекательности)

| Компонент | Метод | Источник |
|---|---|---|
| **Конкурентная среда** | Число POI той же категории в радиусе 500 м | OSM |
| **Плотность инфраструктуры** | Общее число POI всех типов в радиусе | OSM |
| **Прокси трафика** | Близость к транспортным хабам, вузам, ТЦ, паркам | OSM |
| **Демография** | Плотность населения по ячейке | Росстат |
| **Индекс привлекательности** | Взвешенная сумма компонентов (0–100) | Huff model, AHP |

**Важно:** Huff model — классическая модель гравитации в ритейле. Вероятность посещения точки пропорциональна её привлекательности и обратно пропорциональна расстоянию. Для MVP **не используем** — только плотность.

```
│ ГЕОПУЛЬС  [Томск ▾]  [Кафе ▾]              │
├─────────────────────────────────────────────┤
│                                             │
│          КАРТА (MapLibre)                   │
│          ┌─────────────────┐                │
│          │ ████ тепловой   │                │
│          │ ████ слой H3    │                │
│          │ ████            │                │
│          └─────────────────┘                │
│                                             │
│  Легенда: [мало] ──── [много]               │
├─────────────────────────────────────────────┤
│ Клик по ячейке → список POI:                │
│ • Кофейня «X», ул. Ленина 10                │

└─────────────────────────────────────────────┘
```

### Компоненты

| Элемент | Назначение |
|---|---|
| **Селектор города** | Томск (на старте — только он) |
| **Селектор категории** | 8 категорий MVP |
| **Карта** | MapLibre GL JS, центрирована на городе |
| **Тепловой слой** | H3-ячейки, цвет по `poi_count` |
| **Клик по ячейке** | Список POI с названиями и адресами |
| **Легенда** | Градиент «мало → много» |
| **Футер** | «Данные © OpenStreetMap contributors» |


## 5. Техническая архитектура

```
Overpass API (OSM)
       │
       ▼
  Парсер (Python)
       │
       ▼
PostgreSQL + PostGIS  ←── POI с координатами
       │
       ▼
  Агрегация H3        ←── сетка ~200 м
       │
       ▼
  FastAPI (JSON)
       │
       ▼
Next.js + MapLibre    ←── тепловая карта
```

| Слой | Решение |
|---|---|
| Парсинг | Python, `httpx`, Overpass API |
| Хранение | PostgreSQL + PostGIS |
| Агрегация | `h3` (Uber H3, resolution 9) |
| API | FastAPI |
| Фронтенд | Next.js 14 + MapLibre GL JS + `h3-js` |
| Инфра | Docker Compose, VPS |


## 6. Схема данных (минимальная)

```
pois
  id, osm_id, name, category, lat, lon,
  location (GEOGRAPHY), tags (JSONB), created_at

h3_cells
  h3_index, city_id, category, poi_count,
  centroid_lat, centroid_lon

cities
  id, slug, name, bbox (4 координаты)
```

## 8. Что НЕ в MVP

- Индекс привлекательности
- Демография (Росстат)
- Прогноз трафика
- Рекомендации «где открыть»
- Мультигородность (только Томск)
- Монетизация
- Аккаунты пользователей


## 9. Монетизация (после MVP)

| Уровень | Цена | Что |
|---|---|---|
| **Бесплатно** | 0 ₽ | Тепловая карта, 1 категория, базовые фильтры |
| **Разовый отчёт** | 490–990 ₽ | Все категории, экспорт POI, «отчёт по зоне» |
| **Подписка** | 490 ₽/мес | Всё + новые города + обновления данных |

**Логика:** предприниматель в Томске не заплатит 60 000 ₽ (как 2ГИС), но заплатит 500 ₽ за «покажи, где конкуренты».


## 10. Юридические аспекты

- Данные OSM — лицензия **ODbL**, коммерческое использование разрешено, требуется указание источника.
- В футере: «Данные © OpenStreetMap contributors».
- **Не парсим** 2ГИС, Яндекс.Карты, Google Maps.
- Только Overpass API, Overture Maps, Росстат.


## 11. Конкуренты и отличие

| Сервис | Цена | Города | Отличие ГЕОПУЛЬСА |
|---|---|---|---|
| **Яндекс Геоаналитика** | Бесплатно | 16 миллионников | Томска нет → наша ниша |
| **2ГИС Про** | от 36 000 ₽/мес | Миллионники | Неподъёмно для МСП |
| **МТС Геоэффект** | Корпоративно | Миллионники | Не для МСП |
| **МСП.РФ** | Бесплатно | Ограничено | Бизнес-планы, не геоаналитика |

**Отличие:** работаем **там, где гиганты молчат** — малые и средние города. Честно говорим: «Это не прогноз трафика, это карта конкурентной среды».
