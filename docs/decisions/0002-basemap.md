# ADR 0002. Подложка карты

Дата: 28.09.2026. Статус: принято.

## Контекст

Продукт платный (отчёты, подписка) и работает на малые города РФ. Нужна бесплатная или дешёвая
растровая/векторная подложка без юридических рисков. Вариант «по умолчанию» — тайлы `tile.openstreetmap.org`.

## Проблема

Политика OSMF по тайлам `tile.openstreetmap.org`: сервис best-effort **без SLA**, запрещены prefetch,
offline-режим и bulk-загрузка, а коммерческим сервисам прямо рекомендуется учитывать, что доступ
может быть отозван без предупреждения. Использование этих тайлов в платном продукте = риск внезапно
остаться без карты.

## Решение

| Фаза | Провайдер | Условия |
|---|---|---|
| MVP и первая прод-версия | **OpenFreeMap** (`https://tiles.openfreemap.org`) | Бесплатно, без ключа и лимитов, коммерческое использование разрешено, SLA нет; атрибуция «OpenFreeMap © OpenMapTiles Data from OpenStreetMap» (MapLibre добавляет автоматически) |
| Рост трафика / требование SLA | **Protomaps PMTiles self-host** | ODbL «Produced Work», атрибуция OSM; планета ≈ 120 ГБ z0–15, но `pmtiles extract` даёт небольшую вырезку по региону; файлы кладём в свой storage/CDN |
| Резерв | MapTiler / Stadia Maps | Платно по тарифу, ключ + лимиты |

Стиль MapLibre держим в конфиге приложения, URL подложки — в переменной окружения
(`NEXT_PUBLIC_BASEMAP_STYLE_URL`), чтобы смена провайдера не требовала пересборки логики.

## Атрибуция (обязательно)

- «© OpenStreetMap contributors» — на карте, в PDF-отчётах, PNG- и CSV-экспортах.
- Атрибуция провайдера подложки — по его требованиям (для OpenFreeMap достаточно строки выше).
- Ссылка «Сообщить об ошибке на карте» → `https://www.openstreetmap.org/fixthemap`.

## Последствия

- Нет затрат на тайлы до появления ощутимого трафика.
- Нет SLA на MVP — риск фиксируется в ТЗ (раздел 17) и покрывается мониторингом.
- Переход на self-host PMTiles — работа на полдня (скачать вырезку, поднять static-хостинг, сменить URL стиля).
