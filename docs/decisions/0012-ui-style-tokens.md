# ADR 0012. Стили и токены интерфейса: чистый CSS без фреймворка

Дата: 28.09.2026. Статус: принято.

## Контекст

Дизайн-спека v0.1 (`docs/design/design.md`) требовала Tailwind CSS v4, иконки Lucide и
самостоятельно размещённые шрифты Inter и IBM Plex Mono. В проекте при этом уже была вёрстка на
чистом CSS: один `frontend/app/globals.css` (~470 строк) с токенами в `:root`, компоненты
`MapExplorer`/`MapView`/`Legend`/`PoiPanel` со своими классами. Плюс ревью спеки выявило, что
несколько визуальных значений и решений противоречат коду (тёмная шапка, позиция легенды, палитра
шкалы, контраст подписей) — то есть нужно было зафиксировать, кто здесь источник правды.

## Решения

**1. Токены из дизайн-спеки §2 — контракт, реализация — чистый CSS.** Tailwind для MVP отклонён:
UI небольшой (один экран и четыре плавающих элемента), токены уже на CSS-переменных, а переписывание
вёрстки ради синтаксиса утилит не создаёт продуктовой ценности и создаёт риск смешения двух
подходов. Если UI вырастет (порядка десяти экранов, несколько разработчиков в вёрстке), вопрос
возвращается отдельным ADR — миграция линейная, так как цвета и размеры уже вынесены в переменные.

**2. Иконки — Lucide React.** Принято: аддитивная зависимость с tree-shaking, размеры 16/18/20px,
иконки дублируются текстом там, где смысл не очевиден (правило доступности: иконочная кнопка без
подписи обязана иметь `aria-label`).

**3. Шрифты — self-host.** Inter (400–700) и IBM Plex Mono (400–500) подключаются через
`next/font/local`; файлы woff2 и лицензии OFL лежат в репозитории (внешняя зависимость не должна
ломать право на распространение). Числа, счётчики, H3-индексы, координаты и названия выгрузок —
только моно. Отдельное следствие для экспорта: подпись в PNG рисуется на canvas, поэтому перед
`fillText` нужно дождаться загрузки шрифта (`document.fonts.ready`), иначе подпись отрисуется
подстановочным шрифтом.

**4. Доступность — часть контракта, а не пожелание.**

| Правило | Значение |
|---|---|
| Контраст текста | ≥ 4.5:1; проверенные значения: `--text-muted #5F6B76` (5.45 на белом, 4.78 на `--bg-subtle`), `--warning-text #92400E` (6.37 на плашке) |
| Контраст элементов | ≥ 3:1; `--border-strong #8A95A1` для интерактивных границ, обводка пустых ячеек `#7C8794` |
| Focus | `:focus-visible`, outline 2px `--accent`, offset 2px |
| Движение | `prefers-reduced-motion: reduce` отключает переходы и пульсацию скелетона |
| Состояния | `aria-busy` на контейнере карты, `aria-live` для «ссылка скопирована» и ошибок |
| Эквивалент карты | canvas недоступен скринридеру: данные доступны списком объектов в панели и экспортом CSV |

**5. Тени и радиусы.** Тень одна — `--shadow-raised: 0 2px 8px rgba(15, 20, 25, 0.12)` — и только у
всплывающих элементов (легенда, панель POI, модалки, меню). Радиусы ≤ 8px. Обоснование: белая панель
без тени на светлой подложке не читается, но тени «для красоты» и крупные скругления превращают
деловой инструмент в игрушку (раздел 1 спеки).

**6. Порядок применения.** 7a — токены, светлая шапка, позиция легенды и постоянной строки,
палитра YlOrRd; 7b — компоненты (кнопки с иконками, меню «Экспорт», скелетон, состояния, мобильные
чипы); 7c — число классов шкалы (ADR 0006). До применения код и спека расходятся осознанно, перечень
расхождений — в ADR 0008 (уточнение от 28.09.2026) и в чек-листе спеки §9.

## Альтернативы

| Альтернатива | Почему не выбрана |
|---|---|
| Tailwind CSS v4 | Требует переписать существующую вёрстку; токены и так на переменных; для одного экрана не окупается |
| CSS Modules для каждого компонента | Больше файлов и церемоний при том же результате; текущие классы уже читаемы и сгруппированы по компонентам |
| CSS-in-JS (styled-components) | Runtime-стоимость и лишняя зависимость в Next App Router; не даёт ничего сверх переменных |
| Оставить тёмную шапку «как есть» | Противоречит правилу «только светлая тема» и конкурирует с картой за внимание |

## Последствия

- Визуальные правки — в одном файле (`globals.css`) плюс константы карты в `frontend/lib/heat.ts`
  (палитра MapLibre задаётся hex-значениями, CSS-переменные в paint-выражениях недоступны).
- Дизайн-спека и код связаны явно: спека владеет токенами, ADR — поведением; чек-лист §9 спеки
  показывает статус каждого пункта, поэтому расхождение видно, а не обнаруживается глазами.
- Добавляются три внешние зависимости: `lucide-react`, файлы шрифтов и их лицензии (Tailwind не
  добавляется). Это меньше, чем дал бы Tailwind, и не требует переписывания вёрстки.
