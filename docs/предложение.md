# ГЕОПУЛЬС — предложение по структуре интерфейса

## Принцип: «сцены + виджеты» вместо вкладок

Анализ 2ГИС Про, Яндекс Геоаналитики, МТС Геоэффект и СберАналитики показывает: все они строятся по одной схеме — **пользователь выбирает «сцену» (режим просмотра), карта перерисовывается, а рядом появляются «виджеты» — связанные с картой мини-отчёты**. Клик по виджету фильтрует карту.

Это привычнее, чем вкладки: пользователь, работавший с 2ГИС, интуитивно поймёт структуру.

## Режим 1: «Конкуренты» (текущий, MVP)

**Что на карте:** тепловой слой плотности выбранной категории (то, что уже есть).

**Виджеты внизу:**

| Виджет | Что показывает | Что делает при клике |
|---|---|---|
| **Топ-5 районов** | Столбчатая диаграмма: районы с наибольшим числом POI категории | Карта приближается к району |
| **Точки притяжения** | Круговая диаграмма: сколько офисов / вузов / остановок / парков в радиусе 500 м от центра карты | Подсвечивает соответствующие точки |
| **Плотность по районам** | Горизонтальная шкала: районы от «мало» до «много» | Фильтрует карту по выбранному району |
| **Распределение по зонам** | Гистограмма: сколько ячеек в каждом классе плотности | Подсвечивает ячейки класса |

---

## Режим 2: «Инфраструктура» (следующий шаг)

**Что на карте:** слои точек притяжения — офисы, вузы, парки, остановки, парковки.

**Виджеты внизу:**

| Виджет | Что показывает | Что делает при клике |
|---|---|---|
| **Состав инфраструктуры** | Круговая: офисы / вузы / парки / транспорт | Включает/выключает слой |
| **Жилые vs рабочие зоны** | Две полосы: % жилых, % коммерческих | Переключает тепловой слой на жилые/рабочие |
| **Транспортная доступность** | Список остановок в радиусе 500 м | Подсвечивает остановку на карте |
| **Плотность населения** | Тепловой слой по WorldPop (оценочные данные) | Показывает слой плотности |

---

## Режим 3: «Сводка» (для отчёта)

**Что на карте:** карта без теплового слоя, но с выделенными районами.

**Виджеты внизу:**

| Виджет | Что показывает | Что делает при клике |
|---|---|---|
| **Профиль города** | Население, площадь, число POI по категориям | — |
| **Сравнение зон** | Таблица: 3–5 выбранных ячеек по метрикам | Открывает выбор ячеек |
| **Динамика** (позже) | График: как менялось число POI за год | — |
| **Экспорт** | Кнопка: PDF с картой, легендой и таблицей | Скачивает отчёт |

---

## Стандартные названия разделов

Чтобы пользователь, знакомый с 2ГИС или Яндексом, не терялся:

| Не называть | Называть | Почему |
|---|---|---|
| Слои данных | **Конкуренты / Инфраструктура / Сводка** | Привычные термины из 2ГИС |
| POI | **Организации** или **Точки** | Понятно без расшифровки |
| Индекс привлекательности | **Сводка факторов** | Не обещает прогноз |
| Тепловая карта | **Плотность** | Прямое описание |
| H3-ячейка | **Зона** или **Квартал** | Понятно предпринимателю |

## Что меняется в текущем продукте

| Сейчас | Предлагается |
|---|---|
| Один режим (конкуренты) | Три режима: Конкуренты / Инфраструктура / Сводка |
| Виджетов нет | Лента виджетов внизу, меняется по режиму |
| Районы не выделены | Слой районов + сводка по ним |
| Экспорт — CSV и PNG | Добавить PDF с картой, легендой и таблицей |
| Сравнение зон нет | Виджет «Сравнение зон» в режиме «Сводка» |

---

## Порядок внедрения

1. **Добавить слой районов** — без него виджеты «Топ районов» и «Плотность по районам» не работают.
2. **Сделать ленту виджетов** — начать с режима «Конкуренты», 3–4 виджета.
3. **Добавить режим «Инфраструктура»** — после того, как появятся слои точек притяжения.
4. **Добавить режим «Сводка»** — когда будет готов PDF-экспорт.
